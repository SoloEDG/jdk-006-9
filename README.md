# 雾港来电 · 午夜频率

## 安装

使用 Node.js 22.12 或更新版本。

```sh
npm ci
```

## 本地启动

```sh
npm run dev
```

打开终端显示的本地地址。

## Docker 启动

```sh
docker compose up --build
```

打开 http://localhost:8086 。可通过 PORT 环境变量修改端口。

## 路线收听档案

在顶栏点击「路线收听档案」（需要至少两份调查存档），可从两份存档生成各自的连续节目单：

- 按存档中的**历史决策顺序**串联场景录音，标注共同片段与第一次分歧，并可在分歧处切换另一条路线续听。
- 版本还原只依据存档当时已掌握的线索与收听记录，**不会用最终线索重算旧对白**。每个片段标注来源可信度：
  - 已证实：原档收听记录或唯一音源可确定；
  - 版本推断：依据线索取得时点可唯一推断；
  - 来源不确定：原档信息不足，允许跳过，不会冒充准确还原。
- 同步查看两条路线的字幕与线索取得时点（含是否被原档收听记录证实）。
- 对照期间只读原档，暂停或退出都会回到原调查位置，不改动任何存档。
- 节目单是自包含文档：内嵌两份原档快照、字幕、波形与内容指纹；即使原档之后被删除，仍保留可解释的来源说明（音频不可播放时明确标注，而非伪造内容）。节目单单独保存在浏览器中，最多 8 份，可导出/导入 JSON。
